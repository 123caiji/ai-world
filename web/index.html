    怎么验证这些情报

    • 每条都带 evidence：抓取端点、抓取时间、HTTP 状态、在响应里的定位。
    • 缩略图是来源站点自己给的图（image + imageSource），不是 AI 生成；取不到就显示「无素材」。
    • 机器可读全量：data/feed.json · 快照 data/digest.md · 节奏 data/trend.json。
    • 采集脚本全开源：scripts/，源清单 config/watchlist.json。
    • GitHub Actions 定时器每小时探一次窗口（7 * * * *），脚本判断距上次采集满 165 分钟才真正采集；GitHub 丢拍或延迟时，窗口一到的那轮自动补跑。
